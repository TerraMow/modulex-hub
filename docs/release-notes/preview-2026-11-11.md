# Expansion Bay Mechanical Preview — 2026-11-11

This mechanical preview of the TerraMow X side expansion bay includes an updated
mounting reference model and two PDF documents.

## Downloads

- `terramow-x-expansion-bay-preview-2026-11-11.zip` — the three reference files,
  `PREVIEW-NOTES.md`, `LICENSE`, and `LICENSE-NOTICE.md`.
- `SHA256SUMS.txt` — checksums for the archive and extracted files.

| Included reference file | Content |
| --- | --- |
| `Terramow X Expansion Bay Mounting Model.STEP.zip` | Compressed STEP AP214 reference model; about 20.9 MiB, 79.4 MiB after extraction |
| `Terramow X Expansion Bay Rendering.pdf` | CAD rendering, one A4 landscape page |
| `Terramow X Expansion Bay Mounting Hole Drawing_A1.pdf` | Mounting dimensions and screw-type notes, one A3 landscape page |

Open the PDFs with a PDF viewer. Extract the model ZIP, then open the STEP with
FreeCAD, SolidWorks, Fusion, or another STEP-compatible CAD application. The
STEP records millimeters.

## Mounting References

The authoritative mounting-hole drawing is revision **A1**.

The engineering drawing adds mounting-hole locations and dimensions, with notes
for M4 machine screws and M5 self-tapping screws. It describes mechanical
mounting; electrical connector types and pinouts are outside this drawing.

Use the PDF for the exact callouts. Hole depths do not establish screw lengths.
The drawing does not include an explicit unit or general-tolerance statement;
complete manufacturing and integration requirements are not provided here.

## Current Scope

This remains an early reference package. Screw selection details, tolerances,
module loads, keep-out zones, assembly instructions, and validation requirements
are not fully specified. Electrical interfaces, communication protocols,
reference boards, and firmware are not included.

The snapshot date is not a hardware interface version. Specific retail-model
and hardware-revision compatibility is not documented. Public filenames and
STEP name metadata use `Terramow X`; the supplied geometry is preserved. PDF
metadata was cleaned while preserving page content.
